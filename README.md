# Night Line
One number per lunar-night box: the survival line on the team’s printed numbers.

```text
git clone <this-repo>
pip install -e .
night-line --all
```

Writes `out/<box>/{LINE.md,INPUTS.csv,RECEIPT.txt}`. Method: `NIGHT_LINE_SPEC_V1.md`. Record: `LINES.md`. Schema: `night_line_schema_v1.json`. Grant one-pager a PI can attach as professional services: `PO_SCOPE_V1.md`.
