# Night Line — what may be public

SPDX-License-Identifier: MIT

This repository is the **record and the method**: named boxes, cited numbers, a reproducible line, a verifier. It is not an internal plant dump.

```text
pip install -e .
night-line --all
night-line ship-gate
```

`night-line ship-gate` must print **PUBLIC_SHIP PASS** before a push. Exit 1 = do not publish.

## Classes

| Class | Public? | In this repo |
|---|---|---|
| Record | yes | `LINES.md`, `NIGHT_LINE_SPEC_V1.md`, schema, code, sources |
| Method | yes | What a lab uses this for (win the grant / keep the seat / beat the other suite on a recomputable night paragraph), PUG inputs sheet, PUG/ICD shall block, FLIP witness clock, close protocol, LEMS BREAK surface, LEMS measure list, witness map (named box on named host, including NASA-center guests on FLIP, UCF Lunar-VISE, MoonRanger 200 Wh / 4 hrs dark survival, CMU Iris 60-hour mission on a host that never landed, ESA PROSPECT day watts, CSA LEAP LRM ended while the host still lists nights, JAXA SLIM woke after nights it was not designed for, ISRO Pragyan hoped to awaken after a one-daylight design, CNSA Yutu-2 flown RHU heat that is not electrical store, JAXA LUPEX named night-survival tech with the store still OPEN, NASA LEMS-A3 cited electrical store on LINES not a seventh box, Astrolab FLEX 150 h polar darkness, Lunar Dawn operate-through-night, and DIMPLE on CP-32: printed day CONOPS against a Survive-the-Night TO name), and a payload Appendix A night-inputs sheet (TO name is not a watt-hour) |
| Honesty | yes, if no cabin tokens | two courts on LuSEE-Night; two courts on LEMS-A3 leak (TVAC vs CDR vs Fourier) |
| Offer | only after a human GO | `PO_SCOPE_V1.md`, `TO_NIGHT_APPENDIX_V1.md`, `EXPORT_AP_MEMO_V1.md` (W-8BEN / GSA / AP folder) |
| Unknown root markdown | never auto | not on the allowlist in `night_line/ship_gate.py` |

Cabin tokens (internal plant, assumed-fill DIE energy as if it were the Night Line, monorepo paths) fail the gate. Offer pages fail unless `night-line ship-gate --go-offer`.

A new root page does not go public because someone wrote it. It needs a class.
